Списки: вложенность, порядок, пустые и скрытые

Товары, категории, характеристики и меню сайта почти всегда лежат в списках. Здесь — четыре уровня вложенности, смешанный ol внутри li, спецификация в dl и два списка, которые легко потерять: пустой и скрытый.

Дерево категорий: до четырёх уровней

Один и тот же класс tree стоит на каждом вложенном ul — так размечают каталоги, когда шаблон копируют вместе с классом. Верхний уровень — четыре пункта, всего пунктов пятнадцать.

Смешанный список: порядок действий

Внутри ul лежит ol — типичная «инструкция с шагами». Обход ul > li схватит и шаги, если не ограничить глубину.

Спецификация в dl / dt / dd

Список определений — самый удобный формат для характеристики товара: термин и значение идут парами. Один dt может иметь два dd, и тогда наивный цикл «прочитал dt — прочитал dd» съедает второе значение.

def dl_to_dict(dl):
    out, key = {}, None
    for node in dl.contents:
        if getattr(node, "name", None) == "dt":
            key = node.get_text(strip=True)
            out[key] = []
        elif getattr(node, "name", None) == "dd" and key:
            out[key].append(node.get_text(strip=True))   # два dd у одного dt — это нормально
    return {k: (v[0] if len(v) == 1 else v) for k, v in out.items()}

Список без класса

Ни класса, ни data-*: единственный зацеп — структура. Достать его можно через родителя с осмысленным классом или по позиции среди соседей.

Условия доставки

  • Курьер по Тихой Бухте — 350 ₽
  • Почта — от 6 дней
  • Самовывоз со склада — бесплатно
ul = soup.find("div", attrs={"data-test": "delivery-card"}).find("ul")
items = [li.get_text(strip=True) for li in ul.find_all("li", recursive=False)]

# то же селектором: любой ul без class внутри нужной карточки
soup.select('div[data-test="delivery-card"] > ul:not([class]) > li')

Селектор ul:not([class]) в lxml у BeautifulSoup работает, а в стандартном :not() браузера — только с простым аргументом. Если цель — отфильтровать именно отсутствующий класс, проще проверить li.parent.get("class") is None уже в Python.

Ловушки: пустой и скрытый списки

Пустой ul остаётся в разметке, когда товаров в фильтре нет: код, ожидающий «первый элемент всегда есть», падает на IndexError. Скрытый пункт виден парсеру, но не виден пользователю.

    • Складной стул «Бриз»
    • Картуш газовой смеси 450 мл — снят с продажи
    • Фонарь налобный «Светляк 400» — скрыт стилем
    • Гермомешок 25 л

    Видимых пункта в списке reserve два, а в исходнике — четыре. Разница и есть цена слепого доверия первому числу.

    Как обходить вложенные списки

    Три способа задать глубину

    # 1. Только верхний уровень — 4 пункта дерева категорий
soup.find("ul", class_="tree").find_all("li", recursive=False)

# 2. Все пункты вместе: 15 штук, но get_text() у родителя включает текст потомков
top = soup.find("ul", class_="tree").find_all("li")
[len(x.get_text(strip=True)) for x in top]        # длинные строки — это признак «схлопнули детей»

# 3. Свой текст без детей
def own_text(li):
    return "".join(s for s in li.find_all(string=True, recursive=False) if s.strip()).strip()
[own_text(li) for li in soup.select("ul.tree > li")]   # ['Лагерь', 'Свет', 'Посуда', 'Снаряжение']

    Дерево в словарь

    def parse_tree(ul):
    out = []
    for li in ul.find_all("li", recursive=False):
        node = {"title": own_text(li), "depth": int(li["data-depth"])}
        child = li.find("ul", recursive=False)
        if child:
            node["children"] = parse_tree(child)
        out.append(node)
    return out

tree = parse_tree(soup.find("ul", class_="tree"))
