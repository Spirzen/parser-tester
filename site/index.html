Парсинг-тренажёр

Учебный сайт-мишень: выглядит как живой каталог «Тихой бухты», а на деле — полностью статичная, предсказуемая и безопасная площадка. Здесь есть всё, что обычно не находят на реальных сайтах: все уровни заголовков, вложенные div, списки и таблицы, соседние элементы, data-* атрибуты, пагинацию, формы, куки, редиректы, битую разметку, динамическую подгрузку, JSON API, robots.txt, sitemap.xml и RSS.

Нагрузки не будет: это набор файлов. Его можно открыть с диска, поднять локально и повесить на GitHub Pages — и спокойно дать ссылку целой группе.

Три способа работать

1. Только браузер

Откройте любую страницу и справа внизу включите «Тренажёр селекторов»: CSS, XPath и регулярки ищут прямо по открытому DOM, показывают число совпадений, эквивалент для BeautifulSoup и подсвечивают найденные узлы.

Кнопкой в шапке (или адресом ?mode=exam) включается режим без подсказок: разборы в заданиях и сам тренажёр скрываются — так страницу можно давать группе как самостоятельную работу.

2. Локальный сервер

node tools/build.mjs
node tools/serve.mjs --port 8000

Появляются настоящие HTTP-ситуации: 301/302, 429 + Retry-After, Set-Cookie, медленный ответ, windows-1251, JSON API с ?page=. Список эндпоинтов сервер печатает при старте.

3. Деплой для группы

GitHub Pages разворачивает dist/ автоматически (workflow в репозитории). Ссылка одна на всю группу, студент ничего не устанавливает.

Модули

Основы

Запрос и ответ, requests против urllib, кодировки, вежливость парсера и что такое хорошо.

Селекторы

CSS ↔ XPath ↔ BeautifulSoup, вложенные блоки, соседи, атрибуты, data-*, карточки товаров и намеренный шум.

HTTP

Заголовки, коды ответов, куки, редиректы, JSON API, RSS и sitemap как источник ссылок.

HTML-разметка

Заголовки, списки, таблицы, навигация по дереву и битая разметка: три парсера — три результата.

Пагинация

Нумерованные страницы, rel="next", «показать ещё», бесконечная прокрутка, URL-паттерны.

Формы

GET и POST, скрытые и csrf-поля, select multiple, что парсер отправляет вместо браузера.

JS-страницы

Контент появляется позже: ожидания Selenium и Playwright, SPA, shadow DOM, iframe, ленивая загрузка.

Scrapy

Каталог и карточки, цитаты с авторами, правила краулера, фиды и выгрузка без дублей.

Экзамен

12 заданий на одном плотном полигоне и автопроверка ответа без откровений в исходнике.

Быстрый старт на 5 минут

pip install requests beautifulsoup4 lxml
python -c "import requests; from bs4 import BeautifulSoup as bs; \
r = requests.get('http://localhost:8000/basics/hello.html'); \
print(bs(r.text, 'lxml').select_one('h1#main-title').get_text(strip=True))"

Готовые примеры под каждую библиотеку лежат в папке examples/ (requests, urllib, BeautifulSoup, Selenium, Playwright, Scrapy) — они же запускаются в CI, поэтому всегда рабочие.

Правила полигона

  • Все данные вымышлены: магазин «Тихая бухта», люди, города, цены, почты @example.com. Персональных данных нет.
  • Парсить можно всё, включая robots.txt. Раздел /private/ запрещён намеренно — это упражнение на уважение к правилам обхода.
  • Отрабатывайте вежливость даже здесь: User-Agent с контактом, задержка между запросами, повтор только после ошибки.
  • Сайт не меняется между занятиями: структуру правим только осознанно и через docs/AUTHORING.md.
