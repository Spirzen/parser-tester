Шпаргалка сценария: правила, ограничения, выгрузка

Всё, что понадобится пауку по этому полигону: как ходить только по нужным ссылкам, не залезать туда, куда нельзя, и не собрать одну карточку дважды.

LinkExtractor: три способа сузить обход

from scrapy.linkextractors import LinkExtractor
from scrapy.spiders import CrawlSpider, Rule

class QuoteSpider(CrawlSpider):
    name = "quotes"
    allowed_domains = ["example.github.io"]      # полигон живёт в подпапке — домен один
    start_urls = ["https://…/scrapy/quotes.html"]

    rules = (
        # 1) по CSS-области: брать ссылки только из блока пагинации
        Rule(LinkExtractor(restrict_css=("ul.pager", "a[rel='next']")),
             callback="parse_page", follow=True),

        # 2) по regex: allow — «куда идём», deny — «куда точно нет»
        Rule(LinkExtractor(allow=r"item-\d+\.html$", deny=r"index\.html$"),
             callback="parse_item"),

        # 3) по xpath-области: ссылки внутри div.tags
        Rule(LinkExtractor(restrict_xpaths="//div[@class='tags']"),
             callback="parse_tag"),
    )
  • restrict_css=(«область», «ссылка внутри области») и restrict_xpaths — самый точный способ: берём ссылки только из нужного контейнера (пагинация, карточка, блок «Top tags» — не наша цель).
  • allow/deny — регулярки по абсолютному URL; allow_domains отсекает уходы на чужие домены.
  • unique=True (по умолчанию) не возвращает одну и ту же ссылку дважды в пределах одного ответа; process_links — хук для тонкой ручной фильтрации.
  • Ключ dont_filter=True у response.follow отключает дедупликатор RequestQueue — без нужды не трогайте: начнёте собирать дубли.

robots.txt: учимся уважать запрет

На этом полигоне раздел /private/ запрещён в robots.txt (Disallow: /private/). При ROBOTSTXT_OBEY = True Scrapy скачает robots.txt, увидит запрет — и ни одна ссылка на private/index.html не будет запланирована, даже если её явно передать в start_urls (Scrapy всё равно проверит robots для каждого запроса). Это учебная проверка: паук с ROBOTSTXT_OBEY = False на страницу заглянет — и это как раз то, за что в реальном мире банят по IP. Страницы раздела существуют: private/index.html.

Альтернатива разовой выгрузки — FEED_URI + FEED_FORMAT (устаревшая пара) или запуск scrapy crawl quotes -O items.jsonl (Scrapy ≥ 2.4).

Pipeline: валидация и дедупликация

import re
from scrapy.exceptions import DropItem

class ValidateProductPipeline:
    """Пустая карточка или цена без числа — DropItem."""
    def process_item(self, item, spider):
        if not item.get("sku") or not re.match(r"TB-\d{4}$", item["sku"]):
            raise DropItem(f"битый артикул: {item.get('sku')!r}")
        if not isinstance(item.get("price"), int) or item["price"] <= 0:
            raise DropItem(f"цена не число: {item.get('price')!r}")
        return item

class DedupeBySkuPipeline:
    """Одна карточка может встретиться в списке и в деталях — помним первый экземпляр."""
    def open_spider(self, spider):
        self.seen = set()

    def process_item(self, item, spider):
        key = item.get("sku")
        if key in self.seen:
            raise DropItem(f"дубль {key}")
        self.seen.add(key)
        return item
ITEM_PIPELINES = {
    "quotes.pipelines.ValidateProductPipeline": 100,
    "quotes.pipelines.DedupeBySkuPipeline": 300,
    "quotes.pipelines.PriceToIntPipeline": 200,   # «2 490 ₽» → 2490
}

Дедупликация бывает трёх видов: запросов (duplicate filter Scrapy, включён по умолчанию), ответов (HTTPCACHE с нормализацией URL — httpcache_ignore_headers помогает) и item'ов (только руками: множество по sku, как в DedupeBySkuPipeline). Ссылка на карточку из index.html и из item-01.html («хит продаж») даст два одинаковых Item — спасает только третий вид.
