Ошибка 404: страницы нет

Эта страница отдаётся сервером для любого несуществующего пути — удобно отрабатывать обработку ошибок парсера: проверять response.status_code, а не только наличие текста.

Как использовать

  • Запросите заведомо несуществующий адрес: basics/etogostranicy-net.html.
  • requests не считает 404 ошибкой: поднимайте её сами через raise_for_status().
  • На GitHub Pages локальный предпросмотр может вернуть свой 404 — проверяйте статус на живом сайте.

Что проверить в парсере

СитуацияПризнакЧто делать
404resp.status_code == 404пропустить URL, записать в лог «мёртвая ссылка»
403 / 429заголовки Retry-Afterусыпать, снизить скорость, сменить план запросов
200, но заглушкатекст «не найдено» в <body>проверять содержимое, а не только код ответа
200, пустой DOMданные дорисовывает JSSelenium / Playwright или поиск настоящего JSON API
