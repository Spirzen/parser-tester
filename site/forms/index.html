Что парсер делает вместо нажатия кнопки

Браузер по клику собирает значения полей, кодирует их и шлёт на адрес из action тем методом, что указан в method. У requests ровно те же три шага, только их нужно написать руками: прочитать форму, собрать словарь полей, выбрать между params= и data=.

Два режима жизни полигона. На GitHub Pages это чистая статика: форма никуда не отправляется, там нет сервера. На локальном сервере (node tools/serve.mjs) появляется учебный эндпоинт POST /http/echo — он возвращает JSON с присланными полями, заголовками и типом содержимого. Все примеры ниже написаны под локальный сервер и на нём проверяются.

Анатомия формы: три вещи, которые нужно знать

  1. method — get (поля уедут в строку запроса) или post (уедут в тело). Если атрибута нет, браузер использует GET.
  2. action — адрес приёма. Здесь он относительный: results.html означает «рядом с этой страницей». Абсолютный путь вида /search нужно клеить к домену, а # означает «никуда».
  3. Поля — только те элементы, у которых есть name. У элемента без name значения в запросе не будет, каким бы он красивым ни был.

Нажмите кнопку — в адресной строке появится готовая строка запроса. Это и есть то, что соберёт requests.get(url, params=fields).

Один раз collect_fields — дальше любые формы

Функция ниже повторяет логику браузера: берёт name, пропускает отключённые поля, у чекбоксов и радиокнопок смотрит на checked, у select ищет selected, а содержимое textarea читает между тегами. Возвращает она список пар, а не словарь: имена имеют право повторяться (tags[], warehouse из нескольких складов), а словарь хранит только последнее значение.

def option_value(option):
    """Значение опции: value="" -> пустая строка, без value -> текст опции."""
    return option['value'] if option.has_attr('value') else option.get_text(strip=True)

def collect_fields(form):
    """Список пар (name, значение) ровно в том порядке, в каком их видит браузер."""
    pairs = []
    for el in form.find_all(['input', 'textarea', 'select', 'button']):
        name = el.get('name')
        if not name or el.has_attr('disabled'):
            continue                                  # нет имени или поле отключено -> в запроса нет
        typ = (el.get('type') or el.name).lower()
        if typ in ('submit', 'reset', 'button', 'image'):
            continue                                  # кнопка едет только если нажата именно она
        if typ == 'file':
            continue                                  # файлы -> отдельным files=, см. multi.html
        if typ in ('checkbox', 'radio'):
            if el.has_attr('checked'):
                pairs.append((name, el.get('value', 'on')))
            continue                                  # неотмеченное поле не едет вообще
        if el.name == 'textarea':
            pairs.append((name, el.get_text()))
            continue
        if el.name == 'select':
            options = el.find_all('option')
            chosen = [option_value(o) for o in options if o.has_attr('selected')]
            if el.has_attr('multiple'):
                pairs.extend((name, v) for v in chosen)   # ничего не выбрано -> ключа в запросе нет
            elif options:
                if not chosen:                            # браузер считает выбранной первую опцию
                    chosen = [option_value(options[0])]
                pairs.append((name, chosen[0]))
            continue
        pairs.append((name, el.get('value', '')))
    return pairs

def set_value(pairs, name, value):
    """Меняет первое вхождение поля: так выглядит «пользователь набрал текст»."""
    return [(n, value if n == name else v) for n, v in pairs]

Дальше развилка на одну строку — в params= или в data=.

BASE = 'http://localhost:8000'
session = requests.Session()
page = session.get(f'{BASE}/forms/search.html', timeout=15)
form = BeautifulSoup(page.text, 'html.parser').find('form', id='search-form')

pairs = set_value(collect_fields(form), 'q', 'горелка')
url = requests.compat.urljoin(page.url, form.get('action', '#'))   # action относительный

if (form.get('method') or 'get').lower() == 'get':
    resp = session.get(url, params=pairs, timeout=15)               # пары -> строка запроса
else:
    resp = session.post(url, data=pairs, timeout=15)                # пары -> тело запроса
print(resp.url, resp.request.body)

Проверить себя легко: отправьте поле через data= на POST /http/echo и посмотрите в ответ на content_type и fields. Подставите json= вместо data= — fields останется тем же словарём, а content_type поменяется. Именно по этому заголовку сервер решает, как разбирать тело.

Признак, что вы угадали не все поля. requests.post вернул 200, но в ответе форма ругается, или пришёл 403 без текста. Сравните своё тело с телом браузерного запроса до символа: чаще всего не хватает одного скрытого поля или порядка кодирования.

Copy as cURL: самый быстрый способ прочитать чужую форму

Откройте DevTools → Network → найдите запрос fetch или document → правая кнопка → «Copy as cURL». В одной строке лежат метод, адрес, заголовки, куки и тело. Разбираем пример:

curl 'http://localhost:8000/http/echo' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -H 'X-Requested-With: XMLHttpRequest' \
  -b 'session_id=demo-session-42' \
  --data-raw 'csrf_token=a1b2c3d4e5f6&login=ivan.petrov&remember=yes'
Кусок cURLВ requests
-H 'Content-Type: application/x-www-form-urlencoded'data={...} — заголовок подставится сам
-H 'Content-Type: application/json'json={...}
-H 'X-Requested-With: XMLHttpRequest'headers={'X-Requested-With': 'XMLHttpRequest'}
-b 'session_id=demo-session-42'session.cookies.set('session_id', 'demo-session-42')
--data-raw 'a=1&b=2'data={'a': '1', 'b': '2'}
--compressedне нужно: requests распаковывает gzip сам
?q=%D1%81%D0%B2%D0%B5%D1%82params={'q': 'свет'} — кодировать руками не надо

Полезная привычка: после «Copy as cURL» первым делом ищите --data. Если его нет, а метод POST — значит сервер смотрит не на поля формы, а на заголовки или на JSON в другом формате отправки.
