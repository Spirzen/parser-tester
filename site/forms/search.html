GET-форма: семь полей, один адрес

Форма ниже ничего не отправляет на сервер — она просто строит адрес страницы results.html. Ровно то же самое делает парсер: собирает query-параметры и идёт по полученному URL.

Одно текстовое поле — один параметр q. Пустое поле из адреса не исчезает: будет q= со пустым значением.

В адрес уходит value, а не видимый текст: category=свет, а не category=Свет.

Сортировка

У группы радиокнопок одно имя sort: в адрес попадёт ровно одно значение, причём checked существует уже в разметке.

Теги

Несколько галочек с одним именем — повторяющийся параметр: ?tags=титан&tags=поход.

Отмеченная и включённая галочка даёт in_stock=1; неотмеченное поле исчезает из адреса совсем, а disabled не участвует в отправке даже отмеченным.

Форма собирает адрес вида results.html?q=термос&category=посуда&price_max=3500&sort=price-asc и переходит по нему: сервер увидит обычный GET-запрос, тело будет пустым.

Кириллица в query: что видно в адресе

Браузер кодирует значение по UTF-8 и заменяет «небезопасные» символы на %XX. Один кириллический символ — два байта, то есть два %-блока.

from urllib.parse import urlencode, quote_plus, parse_qsl

urlencode({'q': '400 лм', 'category': 'свет'})   # q=400+%D0%BB%D0%BC&category=%D1%81%D0%B2%D0%B5%D1%82
parse_qsl('q=400+%D0%BB%D0%BC')                  # [('q', '400 лм')]  — обратная операция

Ручное кодирование — частый баг: requests.get(url + '?q=' + 'термос') шлёт не-ASCII в заголовке запроса и на части серверов даёт 400. Передавайте значения в params= и не собирайте адрес конкатенацией.

Поля формы одним списком

Соберите атрибуты всех полей — это и есть «контракт» сайта: имена, типы и допустимые значения.

form = soup.find('form', id='search-form')
fields = []
for node in form.find_all(['input', 'select', 'textarea']):
    value = None
    if node.name == 'select':
        selected = node.find('option', selected=True)
        value = selected['value'] if selected else None
    else:
        value = node.get('value')
    fields.append({'name': node.get('name'), 'type': node.get('type') or node.name, 'value': value})
