Эта страница ничего не помнит: весь её вид определяется набором параметров в адресной строке. Откройте её с разными ?… — и увидите, как форма превращается в URL, а URL в список товаров.

Как запустить. Товары читаются из ../data/products.json через fetch, поэтому нужен локальный сервер: node tools/serve.mjs и адрес вида http://localhost:8000/forms/results.html?q=термос&sort=price-asc. Без сервера страница покажет параметры, но список останется пустым.

Параметров в адресе нет, поэтому показан весь каталог без фильтра. Примеры адресов, которые стоит попробовать (и которые стоит собрать регуляркой, когда вы пишете обход):

  • results.html?q=термос — поиск по подстроке
  • то же самое в процентном кодировании — UTF-8, байт на символ больше, чем букв
  • results.html?category=свет — фильтр по категории
  • results.html?price_min=1000&price_max=3000&sort=price-asc — диапазон и сортировка
  • results.html?tags=титан&tags=поход — повторяющийся параметр tags
  • results.html?in_stock=1&sort=rating — только в наличии, по рейтингу
  • results.html?q=снаряжение — пустой ответ: проверьте, как вы обрабатываете «ничего не найдено»

По этому адресу товаров нет. Для парсера это нормальный ответ: проверяйте не «есть ли первый элемент», а длину списка.

Как это парсить

Каждый результат помечен article.result с data-sku, data-category, data-price и data-stock. Но полезнее помнить, что фильтр — это адрес: те же самые выборки собираются запросом к JSON без единого регулярного выражения.

import requests

BASE = "http://localhost:8000"

resp = requests.get(BASE + "/forms/results.html",
                    params={"q": "термос", "price_max": 3500, "sort": "price-asc"}, timeout=15)
print(resp.url)                                   # …?q=%D1%82%D0%B5%D1%80%D0%BC%D0%BE%D1%81&price_max=3500&sort=price-asc
from bs4 import BeautifulSoup

soup = BeautifulSoup(resp.text, "html.parser")
sku = [a["data-sku"] for a in soup.select("article.result")]   # [] — список дорисовывает скрипт
print(sku, soup.find(id="results-count").get_text())           # 0 и '0'

data = requests.get(BASE + "/data/products.json", timeout=15).json()["products"]
print([p["sku"] for p in data if "термос" in p["title"].lower() and p["price"] <= 3500])

Повторяющийся параметр (?tags=титан&tags=поход) в requests собирается списком кортежей: params=[("tags", "титан"), ("tags", "поход")]. Один словарь два значения под одним ключом не передаст.

Отправить форму руками: поиск по каталогу. Разбор форм без браузера — на главной странице модуля.
