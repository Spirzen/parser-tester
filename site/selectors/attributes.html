aria-*: атрибуты для людей, а не для ботов

Подсказка, на которую ссылается кнопка ниже.

Текст панели. ★ — декоративный символ: скринридер его не читает, а парсер заберёт вместе со всем остальным текстом.

Соединение установлено.

Декоративный символ с aria-hidden="true" и подпись aria-label — обычный источник «лишних» знаков в тексте: get_text() соберёт и то и другое. Отфильтровывайте по атрибуту, а не регуляркой после.

Класс из трёх значений

Один элемент, три класса

.card ищет по первому значению, .note-box — по второму, .legacy-promo — по третьему. Точное совпадение [class="card note-box legacy-promo"] требует и порядок, и пробелы, и регистр.

Те же классы в другом порядке

Для .note-box разницы нет, для [class="card note-box legacy-promo"] — есть: атрибут просто не совпадёт как строка.

Кавычки, регистр и пустые значения

  • Имена атрибутов парсер приводит к нижнему регистру: DATA-NOTE в исходнике станет data-note — ищите маленькими.
  • Значения — чувствительны к регистру: data-color="серый" и "Серый" — разные строки.
  • Кавычки в исходнике бывают двойные и одинарные: data-quoted='одинарные кавычки в значении' разбирается так же.
  • Пустое значение data-empty="" — атрибут существует: [data-empty] сработает, а проверка «не пусто» — нет.
  • Значение может содержать пробелы: data-size="48×16×12 см" — не разбивайте его split().

Карточка с точным значением серый.

Карточка с заглавной Серый — для парсера это другой цвет.

В CSS [data-color="серый"] найдёт один пункт из двух. В XPath спасает translate(): translate(@data-color,"АБВ...","абв...") — алфавит придётся переписать целиком. В bs4 проще: [n for n in soup.select("[data-color]") if n["data-color"].lower() == "серый"].
