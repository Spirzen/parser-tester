Пагинация в адресе: файл один, содержимое разное

Файл query.html на диске один. Что в нём окажется, решают параметры адреса: ?page= — номер страницы, ?size= — сколько позиций на странице, ?category= — фильтр по категории. Для парсера это лучший случай: не нужно ни кликать, ни скроллить — нужно подставлять числа.

Как запустить. Список строится из ../data/products.json через fetch, поэтому откройте полигон локально: node tools/serve.mjs → http://localhost:8000/pagination/query.html?page=2&size=6. По file:// список не придёт, и страница покажет только параметры.

Примеры адресов

  • query.html — без параметров: страница 1, размер 6, все категории.
  • query.html?page=2 — вторая страница по умолчанию.
  • query.html?page=3 — третья: позиции 13–18.
  • query.html?page=2&size=6 — размер задан явно.
  • query.html?size=4&page=5 — порядок параметров не важен, пятая страница по четыре позиции.
  • query.html?page=2&size=6&category=одежда — фильтр по категории, значение в адресе закодировано процентами.
  • query.html?category=свет&size=3 — 6 позиций категории «свет», по три на страницу.
  • query.html?page=99&size=6 — страницы не существует: список пустой, data-shown="0", контейнер получает data-empty="true", а статус говорит, что страниц всего 4.

Каталог тот же, что в двух других режимах: 12 товаров и 12 позиций партии уценки, всего 24. С фильтром по категории счётчики меняются — сверяйте их с таблицей ниже.

      URL-паттерн важнее кликов

      Если пагинация живёт в адресе, ломать её не нужно: собираете шаблон, перебираете номера, останавливаетесь по пустому ответу. Клики и прокрутка остаются для тех случаев, когда страница правда не меняет URL.

      import re
import time
from urllib.parse import urlencode

import requests

BASE = "http://localhost:8000/pagination/query.html"

def page_params(page, size=6, category=None):
    params = {"page": page, "size": size}
    if category:
        params["category"] = category        # requests сам закодирует кириллицу в %XX
    return params

page = 1
seen = set()
while True:
    resp = requests.get(BASE, params=page_params(page, category="одежда"), timeout=15)
    resp.raise_for_status()
    print("→", resp.url)                     # ...?page=1&size=6&category=%D0%BE%D0%B4%D0%B5%D0%B6%D0%B4%D0%B0
    text = resp.text
    empty = 'data-empty="true"' in text
    for sku in re.findall(r'data-sku="([^"]+)"', text):
        if sku in seen:
            break                            # дубль: мы вернулись на уже пройденную страницу
        seen.add(sku)
    if empty:
        break
    page += 1
    time.sleep(1)

      Тот же перебор, но с ответом API, короче и надёжнее: requests.get(BASE.replace('query.html', '../data/products.json')).json()["products"]. HTML этой страницы — тренажёр на случай, когда JSON недоступен и данные придётся вынимать из разметки.
