Бесконечная прокрутка: лента догружается сама

Здесь нет ни кнопки, ни номеров страниц. Скрипт следит за нижним маркером через IntersectionObserver и подкладывает по шесть позиций, пока список не кончится. URL при этом не меняется вообще — обходить такую пагинацию «по адресам» невозможно.

Как запустить. Данные берутся из ../data/products.json через fetch, поэтому откройте полигон локальным сервером: node tools/serve.mjs, затем http://localhost:8000/pagination/infinite-scroll.html. Без сервера лента останется пустой.

    Режим#feeddata-mode="infinite" — тот же ../assets/js/dynamic.js, что и на других страницах модуля, поведение выбирает этот атрибут.
    Позиция лентыli.feed-itemатрибуты data-sku, data-index, data-category, data-price, data-batch.
    Счётчик#feed-shownсколько позиций отрисовано: 6, 12, 18, 24.
    Конец ленты#feeddata-empty="true" — дальше сервер молчит, крутить бессмысленно. Атрибут ставит скрипт: до начала работы dynamic.js его нет вовсе, а во время прокрутки он равен false.
    Портрет источника#feeddata-total-items="24", data-shown — то же самое числом, удобно сравнивать со своим результатом.
     
    box = driver.find_element(By.ID, "feed")
while box.get_attribute("data-empty") != "true":
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(1)
items = driver.find_elements(By.CSS_SELECTOR, "li.feed-item")
print(len(items))            # 24

    Ловушка этого способа: позиции 13–24 отличаются от первых двенадцати только суффиксом -У в артикуле. Прокручивая ленту и сохраняя результат, легко записать одну позицию дважды — дедуплицируйте по data-sku или по data-index.

    Почему здесь не обойтись без браузера

    import requests
from bs4 import BeautifulSoup

html = requests.get(BASE + "/pagination/infinite-scroll.html", timeout=15).text
soup = BeautifulSoup(html, "html.parser")
print(len(soup.select("li.feed-item")))            # 0

print(requests.get(BASE + "/data/products.json", timeout=15).json()["meta"]["count"])   # 12

    Разница между «до» и «после» в одном предложении: браузер исполняет скрипт, requests — нет. Поэтому порядок действий всегда такой: сначала найти источник данных (атрибут data-src, вкладка Network, /api/…), потом решать, нужен ли вообще Selenium.

    Признак конца в реальном проекте выглядит иначе: пустой массив в ответе API, отсутствие ссылки rel="next", поле next: null или меньше N элементов в порции. Здесь для учебной простоты выбран атрибут data-empty.
