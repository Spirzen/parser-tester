«Показать ещё»: список догружается скриптом

В исходном HTML списка нет вообще: есть пустой контейнер, кнопка и счётчик. Товары приходят из JSON-файла и дорисовываются по клику — ровно так же ведут себя реальные интернет-магазины с кнопкой «Показать ещё».

Как запустить. Страница обращается к ../data/products.json через fetch, а по протоколу file:// браузер такие запросы блокирует. Поднимите локальный сервер полигона: node tools/serve.mjs и откройте http://localhost:8000/pagination/load-more.html. Без сервера список останется пустым — это тоже часть урока.

Показано 0 из 0 позиций.

    Что здесь происходит

    Контейнер
    ul#catalog с атрибутом data-mode="load-more": режимы infinite и query обрабатывает тот же файл ../assets/js/dynamic.js.
    Источник данных
    data-src="../data/products.json" — 12 товаров. Скрипт добавляет к ним 12 позиций партии уценки (артикул с суффиксом -У, цена ниже на 20 %), всего 24 позиции, порциями по 8.
    Элемент списка
    li.product-item с data-sku, data-price, data-category, data-index, data-batch (значения — основная партия и уценка); у позиций без остатка добавлен data-out-of-stock="true".
    Счётчик
    #shown — уже отрисовано, #total — всего в источнике. После полной загрузки кнопка получает disabled, а статус — текст «всё».
    Состояния
    «подготовка списка…», «идёт загрузка…», «готово: показано 8 из 24», «всё: показано 24 из 24, новых позиций сервер не отдаёт».

    Как это парсить

    Три взгляда на одну страницу
    СпособЧто увидитеКомментарий
    requests.get(url) + BeautifulSoup0 элементов .product-itemHTML без JavaScript: контейнер пустой, счётчики на нуле.
    requests.get('../data/products.json')12 товаров в data.productsПравильный ответ: 24 позиции списка — производные от этих 12, партия уценки достраивается в браузере.
    Selenium / Playwright8 позиций сразу, 24 после трёх кликовНужно ожидание: элемент появляется не мгновенно.
     
    import time

import requests
from bs4 import BeautifulSoup

BASE = "http://localhost:8000"

soup = BeautifulSoup(requests.get(BASE + "/pagination/load-more.html", timeout=15).text, "html.parser")
print(len(soup.select("li.product-item")))          # 0 — списка в HTML нет

data = requests.get(BASE + "/data/products.json", timeout=15).json()
print(len(data["products"]), data["meta"]["shop"])  # 12 «Тихая бухта»
    from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get(BASE + "/pagination/load-more.html")
WebDriverWait(driver, 10).until(EC.presence_of_element_located((By.CSS_SELECTOR, "li.product-item")))

while driver.find_element(By.ID, "load-more").is_enabled():   # в конце кнопка становится неактивной
    driver.find_element(By.ID, "load-more").click()
    time.sleep(1)                                             # ждём порцию, а не гадаем

items = driver.find_elements(By.CSS_SELECTOR, "li.product-item")
print(len(items), items[0].get_attribute("data-sku"))         # 24 TB-1001

    Признак конца списка на этой странице — disabled у кнопки и слово «всё» в статусе. Ни то ни другое не попадает в HTML, который видит requests: если парсите без браузера, читайте JSON, а не кликайте.

    Разметка контейнера

    Все настройки режима лежат в атрибутах контейнера — их и стоит доставать из чужой страницы, когда API неизвестен.

    box = soup.find(id="catalog")
box["data-mode"]          # 'load-more'
box["data-src"]           # '../data/products.json'  ← вот настоящий источник данных
box["data-page-size"]     # '8'
box["data-item-class"]    # 'product-item'
