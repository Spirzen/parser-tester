Не перепутать контекст: iframe и его двойники

Ниже — фрейм с документом iframe-inner.html (src относительный: src="iframe-inner.html"). Настоящие строки поставок лежат внутри фрейма. А сразу под ним — обычная таблица-двойник на той же странице: такие же классы .row-stock, другие артикулы. Ошибка «спарсил не там» выглядит как успешный парсинг.

Как переключить контекст

# Selenium: без switch_to.frame элементы фрейма недоступны
from selenium.webdriver.common.by import By

driver.get(url_outer)                     # ищем .row-stock — найдём двойников снаружи
driver.switch_to.frame("stock-frame")     # заходим внутрь iframe по id/name
rows = driver.find_elements(By.CSS_SELECTOR, "tr.row-stock")   # теперь это TB-FR-*
driver.switch_to.default_content()        # выходим обратно, если нужны внешние узлы
# Playwright: frame_locator не меняет глобальный контекст — безопаснее
rows = page.frame_locator("#stock-frame").locator("tr.row-stock")
data = [(r.get_attribute("data-sku"), r.get_attribute("data-qty")) for r in rows.element_handles()]
# Без браузера: iframe — это просто ещё один URL
from urllib.parse import urljoin
inner_url = urljoin(page_url, soup.find("iframe")["src"])   # src="iframe-inner.html"
inner = BeautifulSoup(urllib.request.urlopen(inner_url).read(), "html.parser")
# важно: requests не исполняет HTML-документ фрейма — но сам файл отдаёт честно

Про base_url. У <iframe> относительный src. Для Scrapy это значит: либо response.follow(iframe_src) (он сам разрешит относительный путь от URL страницы), либо аккуратный urljoin(response.url, iframe_src). settings['BASE_URL'] — про запас для «голых» относительных ссылок без страницы-источника. Тот же приём решает любую вложенность: фрейм во фрейме — ещё один switch_to.frame (или frame_locator дважды).

Признак своего контекста: строки документа фрейма помечены классом .frame-card (накладываете его на строки внутри фрейма и никогда — снаружи). Переключили switch_to.frame зря — .frame-card не найдёте.

Признак «читаю не тот документ»: сравните data-sku с ожидаемым префиксом (TB-FR- против TB-OU-). Делайте хотя бы одну проверку на содержательный признак — по номерам, датам или артикулам.
