Три карточки ниже пусты, пока не попадут в поле зрения: IntersectionObserver из ../assets/js/lazy-table.js заметит это, сходит по адресу из атрибута data-src и впишет сводку. Прокрутите страницу — и вернитесь прочитать этот абзац заново уже с знанием, где были данные.

Главная подсказка модуля: эндпоинт часто виден ещё до загрузки. В исходном HTML карточки уже содержат data-src="../data/products.json" и тому подобные атрибуты — BeautifulSoup достанет список всех «ленивых» URL, и никакой прокрутки не потребуется.

Как читается без браузера

from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")          # один запрос, ноль прокруток
endpoints = [c["data-src"] for c in soup.select(".lazy-card[data-src]")]
# ['../data/products.json', '../data/quotes.json', '../data/reviews.json']

# если атрибута нет, а загрузка хитрая — см. ниже приём «перехватить ответ»
# Playwright: дождаться загрузки конкретной карточки по классу is-loaded
card = page.locator(".lazy-card", has_text="Лента отзывов")
card.scroll_into_view_if_needed()
card.wait_for()                                    # узел виден
page.wait_for_selector(".lazy-card.is-loaded")     # IntersectionObserver отработал
# Selenium: прокрутка к элементу + ожидание class="lazy-card is-loaded"
driver.execute_script("arguments[0].scrollIntoView()", target)
WebDriverWait(driver, 5).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, ".lazy-card.is-loaded"))
)

Два разных урока в одной странице. 1) догружается по прокрутке только отрисовка: сами JSON доступны серверу статичны и берутся напрямую; 2) если бы данных в атрибутах не было, честный путь — ждать появления узлов в DOM (браузер) или перехватить запрос (page.on("response") / вкладка Network).

После прокрутки в карточках появится текст вида «эндпоинт … отдаёт N записей» — сверьте N с реальными файлами products.json, quotes.json, reviews.json.
