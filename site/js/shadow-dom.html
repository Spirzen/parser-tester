Таблица внутри тени: <tb-price-table>

Ниже — кастомный элемент, объявленный в ../assets/js/shadow.js. Снаружи у него пустое содержимое, а вся таблица живёт в его shadowRoot. Посмотрите «View Source» страницы: тег <tb-price-table> закрыт сразу, без единой строки внутри.

Прайс-лист в тени

Почему обычные приёмы не работают

  • document.querySelector('tr') не заходит внутрь тени: стили и разметка изолированы, тень — отдельное дерево.
  • soup.select('tb-price-table tr') вернёт пусто: в исходном HTML содержимого нет, его создаёт JS.
  • Selenium find_element(By.CSS_SELECTOR, 'tr') тоже ничего не находит внутри — CSS-селекторы не пересекают границу тени.
  • Playwright в обычном режиме «просвечивает» открытые тени для части селекторов, но полагаться на это в уроке не будем — смотрите способы ниже.

Три способа достать данные

1. Прочитать shadowRoot через JS-мост

# Selenium: execute_script добирается до свойства shadowRoot (режим open)
rows = driver.execute_script("""
  return [...document.querySelector('tb-price-table')
                 .shadowRoot.querySelectorAll('tr[part="price-row"]')]
         .map(r => [r.dataset.sku,
                    r.querySelector('[part="price-cell"]').dataset.price]);
""")

В Playwright то же самое через page.evaluate(), либо пирсингом селектора:

# Playwright: pierce просвечивает тень
rows = page.locator("pierce=tr[data-sku]").all_text_contents()
# или явно через part-атрибуты стиля (ряд part указан в каждой цепочке)
prices = page.locator("tb-price-table::part(price-row) ::part(price-cell)")
print(prices.count(), prices.all_inner_texts())

2. CSS ::part — «разрешённые окна» тени

Элемент внутри тени помечен атрибутом part (price-row, sku-cell, price-cell). Такой узел можно стилизовать и найти снаружи: tb-price-table::part(price-row) ::part(price-cell). Чтение element.shadowRoot из JS требует режима open, а ::part работает при любом режиме.

3. Не парсить тень вовсе

Часто данные тени откуда-то приходят — ищите эндпоинт во вкладке Network (здесь массив ROWS зашит прямо в скрипт: откройте ../assets/js/shadow.js и прочитайте его как обычный текст — приём «данные видны в исходниках JS-файла» тоже работает).
