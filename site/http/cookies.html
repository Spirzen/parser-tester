Куки: что браузер молча возвращает серверу

Одна кука объясняет, почему «в браузере каталог работает, а в скрипте — страница входа». Разбираем атрибуты, пробуем их руками и забираем то же самое из Python.

Нужен локальный сервер. На file:// браузер не даёт читать и писать document.cookie: тренажёр ниже покажет предупреждение. Запустите node tools/build.mjs, затем node tools/serve.mjs и откройте http://localhost:8000/http/cookies.html.

Анатомия одной куки

Set-Cookie: session_id=demo-session-42; Path=/; Max-Age=3600
Set-Cookie: cart=wagon-7; Path=/http; HttpOnly
Set-Cookie: theme=dark; Path=/; Max-Age=600; SameSite=Lax

GET /http/cookies HTTP/1.1
Cookie: session_id=demo-session-42; theme=dark

Кука cart в ответ не попала: она живёт в области /http и она HttpOnly. Браузер приложит её к запросу автоматически, но JavaScript её не увидит никогда.

То же самое в requests

import requests

session = requests.Session()          # куки хранятся внутри сессии, а не в воздухе
session.headers["User-Agent"] = "TikhayaParser/1.0 (+contact@example.com)"

first = session.get("http://localhost:8000/http/cookies", timeout=10)
print(dict(first.cookies))            # Set-Cookie уже разобраны в CookieJar
print(session.cookies.get("session_id"))
print(session.cookies.get("cart", domain="localhost", path="/http"))

second = session.get("http://localhost:8000/http/echo", timeout=10)
print(second.json()["cookies"])       # то же, что браузер положил в заголовок Cookie

# Set-Cookie в ответе бывает несколько: dict(r.headers) оставит только последний.
print(second.raw.headers.getlist("Set-Cookie"))   # полный список через urllib3

Одиночный requests.get() не сохраняет куки: каждая строка таблицы «исчезает» между запросами. Рабочая привычка — один Session() на весь краулер.

То же самое в Selenium

from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("http://localhost:8000/http/cookies.html")

js_cookies = driver.execute_script("return document.cookie")   # без HttpOnly
all_cookies = driver.get_cookies()                             # все, включая HttpOnly
for c in all_cookies:
    print(c["name"], c["value"], c["path"], c.get("httpOnly"), c.get("expiry"))

cart = driver.get_cookie("cart")               # одна кука по имени
driver.delete_cookie("theme")                  # убрать одну
driver.delete_all_cookies()                    # и всё сразу
driver.quit()

Разница document.cookie и get_cookies() — ровно в HttpOnly. Если задача «достать корзину», а в document.cookie её нет — это не ошибка кода, это запрет на чтение из скрипта.
