Заголовки: половина ответа живёт здесь

Кодировка, тип содержимого, имя корзины куки, адрес редиректа, пауза до повтора — всё это не в HTML, а в заголовках. Разбираем по два списка: что уходит и что возвращается.

Заголовки запроса

Колонка «Кто ставит» честная: часть заголовков браузер запрещает подменять из JavaScript, но requests и urllib ставят их как обычные строки.

Что реально отправляет браузер

Ответ локального эндпоинта /http/echo — дословно то, что увидел сервер. Сравните со своим r.request.headers: набор почти совпадёт, порядок — нет.

{
  "method": "GET",
  "path": "/http/echo",
  "query": { "page": "2" },
  "headers": {
    "host": "localhost:8000",
    "connection": "keep-alive",
    "sec-ch-ua": "\"Chromium\";v=\"124\", \"Not(A:Brand\";v=\"24\"",
    "sec-ch-ua-mobile": "?0",
    "sec-ch-ua-platform": "\"Windows\"",
    "upgrade-insecure-requests": "1",
    "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 TikhayaDemo/1.0",
    "accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,*/*;q=0.8",
    "sec-fetch-dest": "document",
    "sec-fetch-mode": "navigate",
    "sec-fetch-site": "same-origin",
    "accept-encoding": "gzip, deflate, br",
    "cookie": "session_id=demo-session-42; theme=dark"
  },
  "cookies": "session_id=demo-session-42; theme=dark"
}

Заголовки sec-ch-ua и sec-fetch-* — отпечаток браузера. Именно по их отсутствию сервер чаще всего отличает скрипт от пользователя. Если урок про обход таких проверок — честно берите Selenium: он эти заголовки отправляет сам.

Что подставляет requests сам

Accept-Encoding
gzip, deflate — и автоматически распаковывает ответ.
Accept
*/* — сервер не узнает, что вам нужен HTML.
User-Agent
python-requests/версия — первое, что стоит переопределить.
Connection
keep-alive, но только внутри Session: одиночный get() открывает новое соединение.
timeout
не подставляет ничего: без явного значения запрос может висеть неограниченно.

Минимальный приличный набор для учебного парсера: headers={"User-Agent": ..., "Accept-Language": "ru"} плюс timeout и Session(). Остальное — только если сервер действительно просит.
