Первая страница-мишень

Страница намеренно бедная: один заголовок, три абзаца с id, две ссылки и описание в head. Ровно тот объём, на котором удобно проверить, что ваш скрипт работает.

Магазин «Тихая бухта» отдаёт этот документ по методу GET: открыли адрес — получили HTML целиком, без прокрутки и без JavaScript.

Ваша первая задача — не селектор, а выгрузка: заголовок страницы, три абзаца по их id и обе ссылки вместе с адресами.

Проверка простая: если в результате четыре строки, а не три, вы забрали ещё и class="lede". Если семь — захватили навигацию сайта.
