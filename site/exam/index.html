Экзамен: извлеките двенадцать ответов из одной страницы

Все данные для заданий живут на странице-полигоне arena.html. Формулировки ниже говорят, что искать, но не говорят, где: навигацию по разметке вы строите сами. Ответы проверяются локально — никуда не отправляются.

Правила. 1) Откройте полигон и сохраните его HTML (Ctrl+S) или держите открытым в браузере. 2) Каждый ответ — короткая строка: число без разделителей тысяч или текст слово в слово. 3) Регистр, лишние пробелы и «2 490» против «2490» автопроверка прощает; опечатки в тексте — нет. 4) Эталон лежит в data/exam-answers.json в base64 — глазами ответы не считаются. 5) Подсказка не раскрывает ответ. 6) 12 из 12 — «сдано».

Эталон ещё не загружен…

Верно: 0 из 12

E-01 Сколько товарных карточек в блоке «Витрина» на полигоне?

E-02 Самая низкая цена в блоке «Витрина»: число из data-price без «₽».

E-03 Сумма всех data-price карточек блока «Витрина».

E-04 Просуммируйте data-qty строк tbody складской таблицы; итог из tfoot не переносите.

E-05 В ветке «Такелаж» классификатора ровно один пункт третьего уровня вложенности — запишите его дословно.

E-06 Серийный номер барометра из блока «Прибор» — то, что лежит в атрибуте секции.

E-07 На полигоне есть блок, скрытый в браузере, но отлично читаемый из HTML. Запишите его текст.

E-08 Значение скрытого поля формы заявки, в имени которого есть «hash».

E-09 Теги цитаты Инги Приморской на полигоне — списком через запятую, порядок как в разметке.

E-10 Пагинация полигона — заглушка. В файл с каким именем ведёт ссылка rel="next"?

E-11 Итоговая цена со скидкой (data-price элемента с id «final-price»); числа из комментариев-приманок не считаются.

E-12 Карточек промо-акции на полигоне три, и у всех одинаковый data-id. Запишите текст той, что вторая по порядку в DOM.

Как сдавать

import re, urllib.request
from bs4 import BeautifulSoup

html = urllib.request.urlopen(BASE + "/exam/arena.html").read().decode("utf-8")
soup = BeautifulSoup(html, "html.parser")

cards = soup.select("section#showcase .card[data-price]")          # E-01, E-02, E-03
prices = [int(c["data-price"]) for c in cards]
print(len(prices), min(prices), sum(prices))

Фрагмент выше решает ровно три задания из двенадцати — и не подсказывает ничего про остальные.
